# 🌱 Smart Plant Watering IoT System

An intelligent IoT-based Smart Plant Watering System that automates irrigation using sensors, real-time monitoring, and machine learning concepts.

This project helps optimize water usage, monitor soil moisture, and improve plant health through automation and smart decision-making.

---

## 🚀 Features

- 🌿 Automatic plant watering
- 💧 Soil moisture monitoring
- 📡 IoT sensor integration
- 🌐 Flask web dashboard
- 📊 Real-time monitoring
- ⚡ Smart water optimization
- 🤖 Machine Learning integration
- 📈 Data visualization using Plotly
- 🔔 Alert & notification support
- 🧠 Predictive analytics

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Girivardhan-Reddy/smart-plant-watering-iot.git
```

### 2️⃣ Move into Project Folder

```bash
cd smart-plant-watering-iot
```

### 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / Mac

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python app.py
```

Open your browser and visit:

```bash
http://localhost:5000
```

2. Data is sent to Flask backend
3. ML model analyzes plant requirements
4. Water pump activates automatically
5. Dashboard updates in real-time
